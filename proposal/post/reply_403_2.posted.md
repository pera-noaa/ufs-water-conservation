Thanks @JongilHan66. The leak isn't from using sigma surfaces, and diffusing on z surfaces would leak the same way. It comes from applying the fluxes to mixing ratios: neighbouring columns hold different air mass (`delp`), so equal and opposite changes in `q` don't move equal amounts of tracer. A flux-form diffusion conserves on any surface if its face fluxes are mass-weighted (`q·delp`, with each cell's net flux divided by its own `delp`); sigma versus z affects accuracy over steep terrain, not conservation. So it can be fixed on sigma surfaces. It's small, so making it optional is fine for us; if you keep it on, we can test the mass-weighted form.
