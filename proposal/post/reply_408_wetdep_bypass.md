@JongilHan66 Physically it doesn't matter, but for the budget it does, because the tracer tendency already removes it at `eta(k)`. Layer `k` sends `eta(k)*ercko(k)` (before scavenging) through its top, and layer `k+1` receives `eta(k)*ecko(k)` (after). The tracer lost is therefore `eta(k)*c0t*dz*tem`, which is what `chem_pw` has to book. Separately, the borrowing branch sets `wet_dep` to zero before adding it back, so that deposition disappears.
