Thanks @JongilHan66. The leak is not from using sigma surfaces. A flux-form diffusion conserves on any surface if its face fluxes are mass-weighted (`q·delp`, with each cell's net flux divided by its own `delp`); sigma versus z changes how accurate the diffusion is over steep terrain, not whether it conserves. So it can be fixed on sigma surfaces as it is. It is small, so making it optional is fine for us; if you keep it on, we can test the mass-weighted form.
