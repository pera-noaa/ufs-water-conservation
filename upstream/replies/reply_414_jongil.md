@JongilHan66 One caveat before I add it to samfshalcnv: `xlamud` (= 0.001·`clamt`) is shallow's only detrainment, so the floor stops the in-cloud mass flux from decreasing below cloud top. The alternative is to cap detrainment at entrainment below cloud base only, which removes the sub-cloud `eta` > 1 (14 % of convecting shallow columns in `control_p8`, up to 4.1×) and leaves the in-cloud profile as it is. In `control_p8` at 24 h neither changes fields more than a `consv_te` 0.999 perturbation does, and global precipitation moves by ≤ 0.1 %. Which would you prefer?
